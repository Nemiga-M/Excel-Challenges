# Employee Dataset Analysis Project

## 📊 Overview of Excel-Challenges
This repository contains a step-by-step data analysis journey using an **Employee Dataset**.  
Across 8 days, the dataset was explored, cleaned, imputed, and analyzed using Excel formulas, pivot tables, and dashboards.  
The project demonstrates practical data wrangling, descriptive statistics, and visualization techniques.

---

## 📂 Project Structure
- 🗂️ **Day 1 – Data Exploration**
  - Initial dataset review
  - Identification of missing values, duplicates, invalid emails, and inconsistent entries

- 🧹 **Day 2 – Data Cleaning**
  - Applied `CLEAN()`, `TRIM()`, `PROPER()`
  - Converted columns to proper data types (Text, Currency, Date)

- 🔍 **Day 3 – Data Imputation & Basic Formulas (Part 1)**
  - Used `COUNTA()`, `COUNTBLANK()`, `COUNTIF()`, `SUM()`
  - Imputed missing values and summarized department/country distributions

- 📐 **Day 4 – Basic Formulas (Part 2)**
  - Applied `COUNTIFS()`, `SUMIF()`, `SUMIFS()`
  - Department-wise and country-wise salary analysis

- ✍️ **Day 5 – Text Functions**
  - Extracted Employee ID parts using `LEFT()` & `RIGHT()`
  - Standardized names, departments, countries, and emails

- 📊 **Day 6 – Descriptive Statistics & Conditional Formatting**
  - Calculated Mean, Median, Mode, Variance, Std. Deviation, Skewness, Kurtosis
  - Applied conditional formatting for insights

- 📑 **Day 7 – Pivot Tables**
  - Department-wise, country-wise, gender-wise, and performance-wise salary analysis
  - Employee distribution across categories

- 📈 **Day 8 – Dashboard**
  - Interactive Excel dashboard summarizing KPIs
  - Visual insights into salary distribution, employee demographics, and performance ratings

## 🚀 Key Insights
- Salary inconsistencies and missing values were identified and imputed.
- Gender pay gap observed (~7.5k difference between male and female averages).
- "Un-known" category significantly impacted averages and requires reassignment.
- The marketing department had the largest workforce but the lowest average salary.
- India showed unusually high average salaries compared to global benchmarks.
